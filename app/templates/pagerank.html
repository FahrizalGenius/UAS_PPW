Algoritma PageRank Aktif: Perhitungan matriks stokastik berarah dengan penanganan dangling nodes (redistribusi seragam \(1/N\)) menggunakan metode Power Iteration.
Parameter PageRank
Pilih sesi data crawling yang ingin dihitung PageRank-nya.
Peluang pengguna terus mengikuti link (standar: 0.85).
Batas iterasi metode perkalian matriks (standar: 100).
Nilai toleransi perbedaan residual (standar: 1e-6).
Formula PageRank

Rumus perhitungan PageRank untuk setiap halaman \(u\):

PR(u) = (1 - d) / N + d × ∑ (PR(v) / L(v))

Di mana \(d\) adalah damping factor, \(N\) jumlah seluruh node, dan \(L(v)\) jumlah outgoing links dari node \(v\).
